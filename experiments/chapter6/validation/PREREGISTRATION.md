# 冻结原型的追加验证协议

本协议在正式 confirm_v1 实验发起前写入；可机读版本为 protocol.py 和实验 manifest.json。先前 74 次 pilot 已经看过，属于开发依据。本轮检验其后冻结的原型，不把它追溯称为最初预注册。

## 问题与决策

完整 relational 方法在真实 token 上限下，能否相对 niche 保持测试质量或质量约束行为模式的稳定增量？niche 是最小必要对照。若未通过，本轮就不支持完整方法稳定优越，也不因局部有利数据继续调参后合并统计。

两种模型 Qwen3.7-Plus、MiniMax-M3；三类任务 TSP、在线装箱、分类规则；每类 10 个新划分（partition 11–20）；每个模型/任务/划分分别运行 niche 和 relational。合计 120 次。运行顺序由固定随机序列打乱。

每次搜索使用原版 SearchState、planner_prompt、coder_prompt、3 个初始规则和相同解释器。原版控制器源码保持不变，新的数据与预算驱动器单独位于 chapter6_validation。源码指纹在启动前固定。

## 预算

每次总输入加输出上限 60,000 token，planner 单次输出上限 1,800，coder 为 2,000；候选数安全上限 60。输入准入上界为 system 与 prompt 的 UTF-8 字节数加 512。每次调用前，只有余额覆盖该输入上界与完整输出上限才发起；完成后记实际 usage。收到的 usage 必须落在上界内，否则该运行的严格成本比较无效。

准入保守，方法可能留下不同未使用预算，必须报告利用率。因此主结论是“同一预算上限下的搜索”，不称作“完全花费相同 token”。不缩短最后一次回复、不事后丢弃已计费调用。只完成 planner 的末次尝试也计费并记录。没有 usage 的 API 错误使严格成本检验无效；仍报告该运行，不隐藏或自动重跑。

## 数据与指标

TSP/装箱沿用原生成分布与执行规则，使用全新的随机实例。每类分布 2 个 probe、4 个 validation、16 个 test 实例，最终测试实例量为 pilot 的两倍。TSP 仍有精确最优目标值和每个候选统一 24 次局部检查。

分类保持 fit/probe/validation/test 四部分，约 60%/10%/15%/15%，对三个内置数据集做 10 次新的分层划分。各次划分样本会重叠；推断范围是这些数据集的划分和搜索随机性，不能外推到新数据集。所有特征仅由 fit 拟合。

主要质量指标：验证集选择的最佳规则在最终 test 的损失。TSP 为精确最优 gap；装箱为体积下界 gap；分类为三个数据集错误率的等权均值。三类损失不直接合并平均。

主要模式指标：先用共享初始规则的最好验证损失加固定容差作为全方法共同门槛，按 probe 行为去重，保留至多 10 个候选；最终仅保留在 test 也通过共同初始规则门槛者，再按 test 行为去重。容差为 TSP/装箱 0.035、分类 0.025；距离阈值 0.08。原有“自身当前最好值加容差”的动态模式数只作辅助指标。

采用共同门槛是为了避免较差方法拥有更宽的绝对质量范围。该门槛仍是相对给定初始规则的操作性评价，不代表全局最优模式。最终 test 完全不进入搜索提示、父代选择或策略记忆。

同时报告候选数、失败数、重复率、有效增益、输入/输出 token、未用预算、CPU、特征评分次数和全部结果。重复率属于机制诊断，不单独作为有效性验收。

## 统计与通过条件

在各模型/任务单元内，按相同划分配对，10 个差值表示 relational 减 niche。使用配对块均值、95% t 区间、胜/平/负，以及单侧符号翻转检验；穷举全部 2^10 符号。该检验的精确性依赖差值的符号可交换假设，并非任何数据分布下的无条件保证。

24 项检验统一做 Holm 校正：6 个模型/任务单元，各有质量优效、模式优效、质量非劣、模式非劣。质量非劣界为 TSP/分类 0.005、装箱 0.01 的绝对损失；模式非劣界为平均少 0.5 个。上述容许界在结果前固定，不根据实验数据挑选。

某单元通过需满足其一：质量优效与模式非劣均有校正 p < 0.05；或模式优效与质量非劣均有校正 p < 0.05。广泛稳定性门槛：6 个单元至少 4 个通过，覆盖两种模型和至少两类任务，且没有单元的质量差区间整体超过非劣界。任何成本无效的单元不计通过。

这个门槛服务于本轮研究决策，即使通过，也不等价于博士创新性已经证明。通过之后才进入外部强基线和更大任务的正式验证。未通过则如实判定原完整方法的稳定优势尚未建立，并根据失败位置提出下一版机制及其新的、独立的验证计划。

## 不进行的结果驱动操作

不提前结束不利实验；不只汇报显著任务；不把两个模型或三类损失混成一个有利均值；不把候选节点视为独立算法重复；不把追加的阈值敏感性分析冒充主指标；不把外部框架的简化对照称为完整复现。
