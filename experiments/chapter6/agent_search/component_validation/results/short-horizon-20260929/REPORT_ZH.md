# 第六章短程机会成本诊断报告

## 1. 研究目的与边界

本批实验是第六章组件验证协议中的同状态短程诊断，目的在于比较三种固定后续行动：继续开发当前验证集最优程序（C-I）、继续开发冻结的质量接近且行为不同分支（C-B），以及先进行一次无父代探索再开发其有效结果（C-E）。协议计划每个任务使用四个提案、最多八次模型请求；95 个完整任务达到该预算，中断任务除外。所有任务进入终态后才读取独立 test 数据。

本批用于回答“在相同检查点和短预算下，分支或探索后的开发是否值得承担相对于继续 incumbent 的机会成本”。它不是自然搜索确认实验，也不能证明第六章最终方法具有普遍优势。推断单位是数据块；early/late 检查点在块内配对，重复运行不是独立数据块。

## 4. 主要结果

Test gap 越低越好；“相对检查点改善”定义为检查点 incumbent test gap 减去延续结果 test gap，正值表示改善。

| 策略 | 有 test 任务 | 平均 Test gap | 相对检查点平均改善 | 平均已知 token | 平均全局改善次数 | 平均项目/父代改善次数 |
|---|---:|---:|---:|---:|---:|---:|
| C-I incumbent | 32 | 5.1004% | 0.3616 个百分点 | 29,299.6 | 0.625 | 0.625 |
| C-B branch | 32 | 5.1342% | 0.3278 个百分点 | 28,308.6 | 0.531 | 0.656 |
| C-E explore→develop | 31 | 5.3100% | 0.1468 个百分点 | 25,280.2 | 0.161 | 1.452 |

相对于同一 block-phase-repetition 的 C-I 配对，正值表示候选策略的 Test gap 更差：

| 配对 | 配对数 | 平均 Test gap 差值 | 标准差 | 解释 |
|---|---:|---:|---:|---|
| C-B − C-I | 32 | +0.0338 个百分点 | 0.9346 个百分点 | 未显示分支开发的短程优势 |
| C-E − C-I | 31 | +0.2265 个百分点 | 0.6799 个百分点 | 未显示探索后开发的短程优势 |

三种行动相对于各自检查点平均都有改善，但 C-I 的平均改善最大。C-B 的区块均值中有 4 个块优于 C-I、4 个块劣于 C-I；C-E 有 1 个块优于 C-I、6 个块劣于 C-I、1 个块打平（其中一个区块缺少一个 C-E test）。这些结果显示明显区块异质性，不能把 95 个 test 结果当作 95 个独立实验。

## 5. 成本与过程指标

完整任务均恰好完成 4 个提案。C-E 的 31 个完整任务都执行了 3 个探索结果后续开发；中断任务只完成了 1 个探索后续阶段，不能补记为完整的 C-E 单元。按有 test 任务统计，已知 token 均值为 C-I 29,299.6、C-B 28,308.6、C-E 25,280.2。所有任务已知 token 合计为 2,648,325，其中 C-I 937,586、C-B 905,875、C-E 804,864；该合计不含 `sent_unknown` 请求的未知用量。

局部项目改善不能直接替代最终 test 改善。C-E 的父代/项目改善次数较高，但全局改善次数和 test 改善较低，说明“探索后方向在局部继续变好”并不自动意味着它比继续当前 incumbent 更有价值。

## 6. 结论

在本批冻结的 TSP14、新数据块、四提案短预算和 MiniMax-M3 条件下：

1. 三种后续行动都能在部分检查点相对于检查点 incumbent 产生改进，搜索评价闭环能够运行。
2. C-B 相对 C-I 的平均配对 Test gap 差值为 +0.0338 个百分点，C-E 相对 C-I 为 +0.2265 个百分点；本批没有发现分支开发或探索后开发的机会成本优势。
3. 结果不足以永久否定多方向开发，也不足以支持保护或探索机制的最终论文主张。区块数量有限，且一个 C-E 任务发生基础设施中断。

因此，当前证据支持“短程同状态诊断未显示额外方向投资的平均增量”，不支持“第六章完整方法已经被证明正确”。下一步应在不改变本批历史的前提下，修订并冻结连续开发和有限期试用规则，随后开展自然搜索确认实验；自然搜索应保留 C-I/SP 等强简单基线，并继续以区块级配对结果和实际成本作为主要解释单位。
