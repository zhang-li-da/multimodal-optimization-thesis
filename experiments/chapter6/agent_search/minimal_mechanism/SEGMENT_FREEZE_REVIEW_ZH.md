# 续接实验的候选冻结预检

注册续接实验将历史终态保留在多层 `parent_snapshot` 中。原始 `phase_b_study` 的测试入口只读取当前层，不能直接用它替代续接实验的完整终态审查。新增 `segment_freeze_check.py` 只做搜索记录预检，不生成 Test 数据、不评价程序、不解除 Test 封存，也不启动模型请求。

预检保留区块 60–67、早期/后期检查点、I/B/E0/EG、两个重复构成的全部 128 行。它沿不可变证据层定位实际结果，核对输入与候选哈希、终态原因、4/8 步窗口、validation 选择依据、共同起始参考及最多 288 个候选的评价上限。历史未完成任务和未知成本不填零，也不挑出完整配对后丢弃其他行。

即使存在 `halt.json`，未启动任务也不会自动变成终态。无任务终态标记的 `sent_unknown` 是在途请求；有明确终态的未知请求则登记为缺失结果和未知成本。终态/冻结审查通过只表示材料可进入后续 Test 开放审查，不表示 Test 已开放、完整实验已完成或方法有效。
