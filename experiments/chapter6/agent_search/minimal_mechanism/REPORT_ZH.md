## 研究问题与方法边界

本章研究有限生成和评价预算下的外层智能体决策：如何提出有潜力的方向、给它有限试用，并用成熟进展和替代行动的机会成本决定续投、暂存或退出。智能体选择的方向生成、改写、开发对象和预算动作属于外层决策空间；程序、计划、父子关系与搜索轨迹是这些决策的产物；TSP 路线或机器学习参数属于任务内部空间。行为簇变化、项目数量、分支数和局部改进数均不是方法有效性的独立证据。

候选方法保留 A/B/M 的组织方式：A 保存可核验的策略假设、代表程序和行为证据；B 管理有限投资项目；M 记录决策、身份、进展、失败、成本及延迟成熟收益。待检验组件是 G（搜索历史条件下生成方向）、P（稳定项目身份下有限试用与条件续期）、F（根据成熟收益与机会成本分配预算）。精确定义、更新式和伪代码见 [`METHOD_ZH.md`](METHOD_ZH.md)，阶段矩阵与数据边界见 [`PROTOCOL_ZH.md`](PROTOCOL_ZH.md)。

## 假设当前判定

H1–H3 的 TSP Test 结论使用区块级 Holm 校正区间。效应转成正值有利于方法后，**支持**要求区间下限至少 +0.3 pp；**有害**要求区间上限至多 -0.3 pp；**实际收益不足**要求区间完全落在 `(-0.3, +0.3) pp`；其余为**证据不足**。H1/H2 分别报告 Test 效应分类与联合假设分类：联合假设只有在过程门和 Test 都满足支持条件时才支持；Test 达到有害门槛时判有害、Test 区间完全位于实际收益不足范围时判实际收益不足；其余情形（包括过程门失败/不可估但 Test 指向正收益，或 Test 精度不确定）整体为证据不足。阶段 B/C 只诊断和筛查，不判支持。H4 若进入阶段 E，将按每个新任务在 E 前冻结的专属门槛 `δ` 分类；当前未检验。组件若在 C 被删除，对应假设保持证据不足且没有 D 级独立确认，不把筛除当作零效应。未显著不等于无效，未显著变差不等于等效。

| 假设 | 当前判定 | 依据与边界 |
|---|---|---|
| H1：G 的历史信息方向生成 | 证据不足 | 旧 E0 起点较差，但没有 EG−E0 数据；阶段 B 只能作起点/期限诊断，不能宣布支持 |
| H2：P 的有限试用与条件续期 | 证据不足 | E2/S3 检验的是旧保护/排程规则；新身份、额度守恒和机会成本续期只通过离线决策验收 |
| H3：F 的成熟收益与机会成本调度 | 证据不足 | 旧 S3 自适应排程精度不足；新 F 没有真实搜索结果。确认终点冻结为等资源上限下的最终 Test 质量，成本另报 |
| H4：独立数据、宽外层决策空间、另一任务 | 未检验 | 只有 H1–H3 的最小方法在独立确认中获支持后才能进入；旧冻结程序迁移不能代替机制重搜 |

没有一项新 G/P/F 组件已达到“支持”“实际收益不足”或“有害”的实证判定。旧 C-E 的不利信号只适用于旧短程探索动作，不能推广为 G 有害；旧保护/调度区间较宽，也不能解释为等效。

## 六个研究问题的当前回答

1. **哪些组件有独立增量证据？** 目前没有。G/P/F 分别判定；G 无增量可以删除 G，但 P 或 F 仍有可检验依据时可冻结简化候选进入 C。不能用 G 的诊断结果否决整个研究。B 为诊断、C 为筛查、D 才能独立确认；精度不足不能硬判组件无效。
2. **方法是否优于强简单基线并达到实际门槛？** 未知。新方法尚未运行；历史 C-B、S3 固定保护结果均不能回答此问题。唯一确认门槛为独立 D 中 Test gap 至少改善 0.3 pp，且配对区块校正区间满足协议标准。
3. **什么机制改变解释收益？** 当前没有机制能解释新方法收益，因为没有新收益结果。离线记录能区分行为簇、投资项目、谱系和真实行动变化；自然搜索中的组件消融与完整账本才可把具体机制增量和结果联系起来。局部进步数、续期触发或“FULL 最好”都不构成因果解释。
4. **适用条件与失效边界是什么？** 新规则尚无性能边界。历史证据只覆盖窄接口下的 TSP14 短程/小块筛查；旧 E0 在该设置下起点差，旧 C-E 短程表现较差。更宽 TSP 接口、50/100 城市的重新搜索和 ML 机制重搜均未完成。
5. **第六章能提出什么主张？** 当前可写研究问题、决策空间区分、可证伪假设、对历史负结果的独立复核、身份/额度/账本规则及其离线验收。当前不能写 G/P/F 提高解质量或效率、方法胜过 SP/FIX、存在组件协同、可推广到宽 TSP 或 ML。
6. **完整方法无可靠优势时怎样简化？** 先按预设门删除没有独立边际证据的 G/P/F 组件；若组合无 D 级增量，就停止 E 扩张，保留强 FIX 或 SP 为基线/方法，并如实报告零收益、精度或负效应。不能通过加区块、调门槛、挑区块或追加指标寻找正结果。
