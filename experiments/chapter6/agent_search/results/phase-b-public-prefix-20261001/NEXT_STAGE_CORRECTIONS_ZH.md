# 后续冻结前的科学性修订

本文件不影响 e40ce10 的 SP 公共前缀，不授权调用，也不宣称现有控制器已完成以下修订。下次方法/协议冻结须落实。

## 统一跨行动收益

项目进展 `max(0, project_best_before-project_best_after)` 只作有限试用/续期的辅助证据。跨 I/B/E 的主收益统一为同损失尺度的全局最好质量贡献，不能再对局部和全局收益率取最大值。

事件 `g_t=max(0, global_best_before-global_best_after)` 在全局账本只记一次，项目账本可以引用但不能重复相加。成熟过程收益率为 `sum(g_t assigned to process)/total process tokens`。探索和后续开发以预定起止组成过程；未结束过程为 pending，不得先当零样本。I/B 开发也按预注册窗口成熟。局部追赶映射到未来全局收益必须独立验证；当前不训练复杂调度器。具体窗口、估计器和决策表需在 B 诊断之后另冻，本文件不是可运行的新 F。

## 阶段门按剩余主张推进

G 无优势不自动终止 P/F；已有分支开发仍有可检验回报时，可研究简化 P/F。若只有 G 有价值，则比较 G 加简单固定开发；若全部没有可辩护的作用，则保留 SP/固定多分支并停止扩张。未显著不等于无效，未显著变差不等于等效。本批 1/16 可用 checkpoint 不能估计这些效应，当前不选择 M* 或进入 C。FULL 最好不构成协同证据。

## D 的功效必须对应实际收益主张

若要求收益区间下限达到 `delta_0=0.3 pp`，规划必须指定 `delta_A>0.3 pp` 的预期真实效应，并用其与门槛的距离计算。两项比较保守双侧 Bonferroni 区间的正态近似是：

```text
m=2; alpha=0.05; power=0.80
N=ceil(((z[1-alpha/(2*m)]+z[power])*sigma_block/(delta_A-delta_0))**2)
```

量纲统一用 pp；用 loss 时门槛为 0.003。`delta_A<=delta_0` 无法按该成功规则设计常规 80% 功效。旧公式除以 0.003 只适合相对零检出 0.3 pp 的目标。代数例：假设真实效应 0.5 pp，分母应是 0.2 pp；同一 sigma 下样本量为错误用 0.3 pp 的 2.25 倍。这不是实际 N 建议。

最终 N 在新确认数据前，基于独立开发区块差值波动保守估计，用配对 t 或正式仿真核验实际多重比较规则和至少 80% 功效。须明确是每比较功效还是两比较均通过的联合功效；主张要求两项均通过时应按联合成功率规划。固定 N 或正式序贯规则不能事后补跑。当前不能从一块未完成前缀估计配对 Test 波动，N 仍未确定；资源不足时明确为估计性实验。
