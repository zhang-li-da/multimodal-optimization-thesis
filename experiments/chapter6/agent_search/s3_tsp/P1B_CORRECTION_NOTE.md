# P1b 复核补记

本轮从 P1b 的已发布 `raw-study.zip` 逐项复算 checkpoint 和原始响应，未重新调用模型，也未改写冻结批次。

复算得到 192 个提案中 114 个有效；78 个响应因长度上限截断，其中 planner 67 个、coder 11 个。保护组中有 6 个有效、无父代探索候选满足当时的质量竞争门槛，但没有候选进入 B。两组总计对应 16 个这类探索候选。

保护组 9 个 B 准入候选均在准入时刷新全局最好。14 个保护时隙中，13 个选择当时全局最好父代；2 个相对父代改进案例也都发生在全局最好父代上，因此没有一次测到“保护落后方向并从该方向继续改进”的目标情形。只有 1/8 个保护运行的最终最好程序包含保护开发祖先。

因此，P1b 证实的是：旧控制器曾安排保护提案，但探索到开发的准入链断开、输出截断率较高，而且落后方向的保护没有被有效检验。它不能证明保护有效，也不能证明新方向机制无效。旧版结果仍按原协议报告；本补记负责更正对“保护流程已充分曝光”的解释。
