博士论文总体架构与第六章技术报告

整理日期：2026 年 9 月 23 日

范围： 依据工作区中的博士论文架构说明、已提供论文材料、第六章 demo 与冻结追加验证，汇总论文主线、系统实现、实验结果和当前限制。本文用于科研讨论和开题/中期材料准备，不替代各篇论文的正式书目信息核验。

一、结论先行

目前能够作出的判断需要区分三个层次：

  1. 工程可行性已有实证支持。 已实现一个真实大模型驱动的程序搜索闭环：模型提出策略并生成受限 Python 评分函数，隔离解释器评估函数，外层控制器保存质量、行为和执行记录并安排后续搜索。系统在 TSP、在线装箱与小型分类规则发现任务上运行过多轮，完整输入、响应、usage、候选程序和回放信息得到保存。
  2. 原型机制有研究价值，但完整 A/W/M 版本的稳定优势未得到支持。 早期 pilot 出现过个别改善信号；预注册冻结追加验证中，六个“模型×任务”单元没有一个达到事先规定的质量—多样性通过门槛。因此不能据此声称 relational 方法优于简单小生境，也不能把“降低重复”直接解释为“找到更好的算法”。
  3. 第六章可作为有证据的问题驱动研究方向，尚不能按已验证的新算法定稿。 观察到的 probe 误判和“把有益局部开发判成重复”的反例，为重新定义机制提供了具体动机。下一版应聚焦质量保护下的行为关系辨识和搜索资源分配，并重新冻结、独立验证；若新增机制不超过简单基线，应相应收窄论文贡献。

这意味着：方向科学、原型可运行、证据可审计；但方法是否有效、相对近期强基线是否有独立创新，仍待后续实验回答。

二、博士论文总体架构与前五章工作

论文主线从多模态优化基础理论出发，逐步处理专家经验与评价、单目标离散/连续优化、高维多目标优化，最后探索这些搜索思想在 LLM 自动算法发现中的迁移。第一、二章主要承担铺垫；第三至五章建立多模态搜索方法；第六章是面向新搜索对象的迁移与验证。

章节 拟定内容与研究问题 对应工作/文章 当前状态与边界
第一章 绪论：研究背景、问题、贡献与论文组织 无单独对应论文 综合提出多模态搜索与自动算法发现的研究动机。
第二章 多模态智能优化基本理论与文献综述 无单独对应论文 梳理多模态单目标、多目标、决策空间多样性及评价方法，为后文统一术语。
第三章 专家经验辅助的多模态智能优化算法设计 ① A Review of Evolutionary Algorithms for Multimodal Multi-objective Optimization: Mechanisms, Progress, and Prospects；② A Parameter-Free Joint-Space Metric for Multimodal Multiobjective Optimization；③ 多模态测试问题设计（尚未完成） 综述归纳机制发展；联合空间指标关注目标质量与决策空间分布。指标依赖参考集等评价条件。测试问题设计仍是本章待完成工作，不能在目录中当成已有成果。

第五章 双空间协同演化的高维多模态多目标优化 High-Dimensional Multimodal Multi-Objective Optimization via Subspace Projection and Angular Diversity Management（HDADE） 以子空间投影和角度多样性管理应对高维决策空间下的质量与决策分布平衡。
第六章 面向自动算法发现的执行反馈多模态搜索与关系记忆 本报告所述 agent 原型；MLEvolve 为重要启发和相邻框架 研究外层算法规则/程序搜索中，如何识别行为模式、保护有用开发、利用执行关系并控制成本。当前原型不是 MLEvolve 的复现，也未覆盖一般机器学习训练管线。

前后章节的概念连续性和迁移边界

  • MSLS-MA 给出离散搜索中“保留质量相近但结构不同的方案、做局部开发、停滞后重启”的直接启发。第六章把搜索对象提升为能处理一组实例的评分程序；这不是把 MMTSP 算法本身交给 LLM 重跑，也不是对 MSLS-MA 全算法复现。
  • RMC-CMSA 启发记录起点、过程、终端及其关系，并把状态用于重启资源决策。第六章的 A/W/M 借用了这一思路，但程序搜索中的轨迹语义并不天然等同连续优化轨迹。尤其分类任务保存的预测前缀不是训练动力学证据。
  • HDADE 支持分别考察质量与高维行为分布的原则。本 agent 没有把随机子空间投影直接移植到程序空间，也没有证明其行为描述符保留程序空间拓扑。
  • DWD 联合空间指标建立在任务和参考集定义之上。开放程序空间没有已知完整参考集，因此当前报告只谈有限 probe 上的操作性行为模式，不使用 DWD 或 PR 声称恢复了真实全局模式。

三、第六章研究问题与系统实际架构

3.1 研究对象和待验证问题

系统搜索对象是受限程序空间中的评分/决策规则：外层保存一组可执行规则，每个规则作用于多个实例并诱导路线、装箱选择或类别预测。应区分外层规则的行为模式与内层单个实例上的解。当前“模式”按固定 probe 上的行为相似度操作性定义；它不是已证明的吸引域、局部最优盆地或程序语义等价类。

本章目前最具体的问题是：在固定调用/评估预算下，有限执行 probe 能否可靠区分程序行为；在质量约束下，如何保留有收益的同模式开发，同时避免把无收益重复搜索反复计入；父代、操作、意图、轨迹与终端结果的关系能否帮助分配后续搜索；这些信息带来的收益是否超过额外 token 与评估成本。

MLEvolve 的跨分支引用、长期记忆和 planner/coder 分工构成问题背景，但这些功能已经由 MLEvolve 等工作涉及，不能直接写作本章首创。系统尚未完整复现 MLEvolve、SeaEvo、AdaEvolve、FunSearch 或 GEPA。

候选函数由真实模型生成，而不是从预置参数网格中选择。执行层使用受限 AST 解释器，不允许候选任意导入库、访问文件或网络、使用循环或反射。这个保护边界也限定了研究结论：它是有界规则发现 agent，尚不是任意 AutoML 系统。

3.3 多模态机制在 v1 中的具体实现

记号 实际保存内容 在搜索中的作用 当前不足
A：质量/行为档案 质量较好的程序；在任务固定 probe 上的行为描述；小生境代表 质量门槛后保留若干行为不同的规则，避免只留单一最优文本/规则 probe 距离易误并/误拆；质量进步与碰撞惩罚可能同时触发。
W：执行轨迹/中间状态 TSP 局部改进前后的路线状态；装箱状态前缀；分类预测前缀等 给候选复用提供过程证据，尝试辨识构造轨迹到终端行为的关系 跨任务语义不一致；分类前缀不代表训练过程；其独立增量未建立。
M：关系与结果记忆 意图/计划标签、父代、操作、执行终端、改进、重复/碰撞、失败和成本 让后续选择依赖历史操作结果；控制器可继续、重组、重启或重新激活 记录 token 不等于按 token 净收益调度；关系计数可能混淆收益与重复。

原控制器包含 quality、niche、terminal、relational 等内部机制对照，并运行过 relational 去 W 消融。Pilot 阶段样本较少，且这些对照不等于外部完整框架复现。v1 主要按标签、收益和碰撞规则调度，没有直接优化每 token 的预期净收益。

四、已完成实验与结果

4.1 早期真实模型 pilot

  • 共运行 74 次正式实验；模型为 Qwen3.7-Plus 与 MiniMax-M3。另有模型连通性检查，不并入正式实验统计。
  • 真实候选生成尝试 888 次，其中 865 个有效、23 个失败；失败仍纳入尝试记录和预算口径。
  • 有 usage 的模型调用 1,775 次，累计记录 2,563,223 tokens。保存 244 个不同“最终程序—数据划分”组合的回放核验结果，19 项协议/执行器测试通过。
  • 任务包括 12 城市 TSP、在线装箱和 Iris/Wine/Breast Cancer 分类规则发现。比较机制包括 quality、niche、terminal、relational 和 relational_no_w 等。
  • 观察到的局部信号并不一致：Qwen 分类 relational 的测试错误率为 5.49%，niche 为 6.85%；但 Qwen TSP niche 为 4.25%，relational 为 4.61%；装箱各方法的最好测试 gap 相同。重复行为下降并不必然带来质量或模式收益。

这轮 pilot 支持“模型生成规则的闭环能够运行”和“执行行为记忆会改变搜索决策”，不构成稳定优效证据。很多任务只有 3–5 次重复，结果只适合提出后续假设。

4.2 冻结追加验证

原控制器、提示和核心源码冻结，运行 2 个模型 × 3 类任务 × 2 个控制器 × 10 个新划分 = 120 个区块。每个区块输入加输出 token 上限为 60,000，采用预注册的共同质量门槛。MiniMax 首批高并发发生限流后，在观察效果之前登记降低并发并对整个提供方批次重跑；原有 24 个保存区块仍单独保留，没有按结果择优拼接。

4.3 机制诊断与反例

  1. 相似不等于无收益重复。 复核的 TSP 程序对在固定 probe 上行为距离为 0，但加入 regret 项后，验证 gap 从 0.073245 降至 0.062208。旧 pilot 的部分有质量提升候选同时被标记为 probe 碰撞。原控制器对碰撞施加负项，可能压制有价值的同模式局部开发。
  2. 模式关系依赖 probe 和分布。 256 状态、可枚举真值的检查显示，6 个随机 probe 会把仅在稀有状态分歧的程序大量误合并；加入独立 witness 可降低已知域的错判，但需要更多执行样本。该检查没有证明 witness agent 的搜索表现更好。真实任务中 TSP 的 probe 为 10 城市而验证/test 为 12 城市，分类与装箱也有 probe/test 关系不一致现象，有限采样误差和规模迁移混在一起。
  3. 降低重复率不是充分目标。 Qwen/装箱 relational 的测试模式数低于 niche（2.80 对 5.10），但测试 gap 几乎相同；分类的 relational 结果也未在新划分重现 pilot 中的优势。
  4. 固定分类器参照说明任务能力边界。 在相同分类划分上，按验证选择六种固定分类器得到约 3.41% 平均测试错误率。它不是同 API、同程序语言、同调用预算对照，也不能当作对 agent 的公平基线；它说明当前受限规则搜索不应被描述成已达到完整 AutoML 性能。

六、科学性、可行性与创新性判断

科学性

研究问题可以形式化：给定有界程序空间、实例分布、质量门槛、行为描述与成本预算，研究模式辨识误差如何影响候选保留和后续搜索，并检验关系信息能否带来质量或多样性增量。已有负结果、反例和冻结协议使假设可以被否证。科学性来自可操作定义、可复核实验和明确的失败解释，不等于预先断言新方法有效。

工程可行性

当前闭环已真实运行，调用预算、程序执行、回放与失败均有记录，CPU 规则评估可承担现有小规模任务。coding plan 减少经费障碍，但不消除 API 限流、服务超时或并发限制。现有证据没有测得真实模型训练任务的 GPU 时间、显存和吞吐，故不能据小任务承诺大模型训练级算法发现的墙钟周期。

创新性

MLEvolve 已覆盖跨分支引用、记忆和规划/编码分离；FunSearch 有执行分数签名聚类与岛屿机制；SeaEvo 已有策略簇和互补检索；AdaEvolve 已有质量/多样性档案与自适应分配；GEPA 使用轨迹反思、Pareto 选择及跨谱系组合。因此，“将多模态优化加入 LLM agent”或“A/W/M 组件组合”本身不足以确立新颖性。

可以进一步检验的贡献候选是：质量保护、对关系不确定性有显式处理、并按验证增益与成本分配资源的执行行为关系搜索。它仍是候选，不是当前已证明的新方法。其成立至少需要在可枚举机制基准、真实程序发现任务、近期强基线与独立任务集上显示不可被固定大 probe、质量 UCB、小生境或简单关系计数替代的增量。

七、建议技术路线与第六章验收标准

  1. 先修正机制定义。 分开“行为相近”“严格/近似等价”“无质量/用途增益重复”和“关系不确定”。质量进步优先保护；未能确认关系时保留未决并计算 witness 成本。
  2. 先做可枚举辨识，再接真实模型。 明确有限语法、全域行为真值、质量合格模式和变异邻接。比较固定小/大 probe、witness、随机关系和文本/评分签名；至少报告误并、误拆、未决、成本及真模式召回。
  3. 做最小归因实验。 质量档案 A × 关系记忆 M 的 2×2 起步；再依次检验 W、witness、成本感知和重启规则。真实执行关系与打乱关系、仅计数关系、质量 UCB 及更大固定 probe 都要对照。
  4. 按预算公平比较。 同时登记 token、候选数量、评估次数和墙钟；模型调用失败、候选执行失败及 API 成本分开记载。主分析按同 token 上限，另报告实际耗用，不从有利轨迹截断拼接。
  5. 扩展真实任务和基线。 先扩充算法规则发现，再加入至少一类优化器/训练更新规则或 ML 管线模块发现；按任务级抽样，锁定模型、任务、数据划分和外部框架 commit。作者版复现和统一接口适配分开评估。
  6. 冻结独立确认集后再作结论。 质量和多样性/用途各设主指标与非劣界；任务是最高推断层，不能把同一数据集的多个划分当作不同数据集。完整报告效应量、区间、多重校正、最坏任务、成本及失败案例。

博士章节最低验收条件：方法状态、等价/模式/关系、用途和成本定义完整；至少一个新机制相对简单小生境、质量 UCB 和近期适用方法有独立增量；A/W/M 消融能解释增量来源；质量与实际用途在独立任务上达到预注册门槛；至少有一类真实机器学习算法或模块发现任务；源码、提示、模型版本、数据划分、失败日志和统计脚本可复核。若只证明可运行或只改善重复率，章节应限定为程序空间执行关系辨识/失效分析研究。
