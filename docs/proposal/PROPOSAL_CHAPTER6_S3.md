# 第六章开题研究内容：S3 实验后的修订

更新日期：2026-09-27。本文承接 [智能体探索—开发研究设计](PROPOSAL_CHAPTER6_AGENT_SEARCH.md)，依据本轮真实 S3 r3 结果收缩主张，不改写历史协议。

## 拟定题目与科学问题

**面向自动算法发现的多方向搜索与成本受限分支开发方法。** 研究对象是智能体外层的程序修改与资源决策，TSP 内层路线只提供执行行为观测。最终输出一个最佳程序即可满足目标；多算法集成不是本章成立的必要条件。

核心问题是：有限评价下，如何区分已知规则重现、局部改进和足以值得后续预算的方向，并让暂时落后但有潜力的分支获得有限机会，同时控制机会成本？“保护更多方向”本身不是优化目标，最终应以独立测试质量、达标概率及总成本衡量价值。

## 与前序章节的关系

第三章的机制综述及 DWD 联合空间评价为质量、行为和机制分开评价提供依据；第四章 MSLS-MA 的多结构局部开发、RMC-CMSA 的基于实际过程分配重启资源，为外层方向保存和开发提供研究动机；第五章 HDADE 的双空间思想帮助区分质量与执行行为。对象由一个优化解变成产生解的程序，其方向定义、可重复性和有效性必须重新建立。

对应文章清单、实际状态与技术流程见 [S3 架构报告](../chapter6/S3_ARCHITECTURE_ZH.md)。第一、二章的基础性讨论及第三章尚待完善的测试问题设计保持原论文架构。不能把前章算法的结论直接作为本章有效性证据。

## 已建立的研究基础

S3 完成 MiniMax M3、六个实验组、八个新数据块的 48 次自然搜索。1,536 个提案中 1,527 个程序有效；全部搜索和独立测试完成。真实日志中，无父代探索能够获得开发资格，落后分支获得 366 次保护机会，362 次形成有效评价。全部决策和程序重执行通过，足以支持原型可行性和方法问题研究。

但主效果仍未通过：FB_P−FB_U 平均增加 0.1909 个百分点 Test gap，AD_P−FB_P 增加 0.0738；TS_P−FB_P 平均减少 0.4105，但描述性区间跨零。单路径开发 SP 的平均 Test gap 最低，为 5.0969%。因此不主张“保护”“反馈调度”或完整多模态智能体已经优于简单基线。

TSP50/100 的独立冻结迁移评价已完成，不新增模型调用。它仅检验 TSP14 发现规则的跨规模执行，采用启发式路线参考，不等于在大规模重新搜索或跨任务验证。完整结果与所有负例见 [技术报告](../../experiments/chapter6/agent_search/s3_tsp_r3/results/s3-minimax-strategy-20260927/TECHNICAL_REPORT_ZH.md)。

## 拟研究方法与检验路线

主体保留候选历史 C、输出代表 A、有限开发池 B 与反馈记录 M。试用准入依据有效性、质量约束和观测行为差异；续额依据方向内的实质进展；每个方向账本记录已授予和实际消耗。程序选择、失败、费用及输出冻结都需要可重放。方向是有限证据下的操作性类别，不宣称真实盆地识别。

下一阶段首先修正零额度条目占池的实现边界，在明确的动作单元上建立强简单分配基线，然后独立比较保障时序、保障对象与是否继续保留分支。反馈自适应必须与同两步单元的固定概率策略比较，排除动作组织差异；若直接奖励无法描述探索的延迟贡献，再研究延迟反馈，不能先假定加入更多记忆必然有效。

验证过程为“实现语义验收—真实同状态分叉解释—全新数据上的自然搜索比较—必要消融—独立任务确认”。自然搜索无触发的运行仍计入总体表现。主要比较、实际收益阈值和失败规则提前冻结，样本量依据最终机制的区块方差与目标精度规划。本轮是筛查，不能追加到显著后伪称一次确认实验。

## 预期贡献及边界

可检验的候选贡献是：将方向试用和方向进展区分，以可兑现且有上限的开发机会协调探索与集中开发，并建立资源投入到最终方案质量的机制证据。当前已经建立执行证据，增量有效性与文献新颖性尚未确立；完整关系图、W、witness、多 agent 分工不是必须保留的贡献。

如果简单分配更好，保留简单方法并说明机制失效条件；如果保护只在特定任务、噪声或预算区间有效，报告适用范围。博士章节应围绕一个被充分验证的问题与结论形成，不能由 API 接通、工程规模或单个成功 demo 代替方法贡献。
