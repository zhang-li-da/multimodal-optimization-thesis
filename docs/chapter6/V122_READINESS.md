# 第六章 v1.2.2 启动层：从可测控制器到可恢复搜索

本维护版依照 [PR #1 复核](reviews/v121/REVIEW.md)及其[阶段 A 方案](reviews/v121/EXPERIMENT_PLAN.md)实现。研究命题与 `V121SearchState` 的两臂规则不变；工程版本单独编号 v1.2.2。没有执行新的模型搜索。

| 复核问题 | 实施位置 | 验证证据 |
|---|---|---|
| ZIP 跨平台读取失败 | `v12_2/archives.py` 的唯一规范名称索引 | 原 18 个结果字节哈希、正反斜杠与冲突成员测试 |
| AST 展示格式影响身份 | `v12_2/identity.py` 显式 AST schema | 327 个历史有效评价在 Python 3.12/3.13 的代码与结构身份核查 |
| 清单包含未发布 pyc | 从 Git 跟踪发布路径生成清单 | r2 23 个实际文件 |
| 新控制器没有启动器 | `v12_2/cli.py` / `runner.py` | 显式控制器类、假模型全链路和参数/数据/源码绑定 |
| 恢复可能少扣/重扣额度 | `calls.py` 请求状态机与逐步 choose/observe 回放 | 多种中断点、未知响应拒绝再发、额度与成功深度核对 |
| test 在同一流程中执行 | 搜索与 `test_stage.py` 分开 | 修改/禁止读取 test 不影响搜索；最佳程序与种子均按 validation 选择 |
| 有多分支但无族信息差异 | `branch_exposure()` | distinct tags、族分数变化、full-vs-gain 选择及质量差 |

具体命令、输出结构和已知限制见[维护版说明](../../experiments/chapter6/v12_2/README.md)，最终离线证据见[技术报告](../../experiments/chapter6/v12_2/results/readiness-20260925/REPORT_ZH.md)。

本版仍采用 A（输出代表）/B（有限开发机会）/M（已执行候选事件）的研究结构。新增启动层保证证据能够按明确顺序产生和恢复，不将启动层工程本身宣称为多模态优化创新。对真实性能有意义的下一观察仍是：受保护分支获得实际模型续接后，是否在相同提案数下优于 FIFO，以及实际 token 成本是否值得。

固定候选流驱动的策略状态探测会给新父代赋予旧评价，因此只能检查状态路径；本版假模型夹具同样不能估计真实搜索的反事实收益。确认两臂仅在同一状态的 B 排序上不同，由同状态克隆测试完成。
