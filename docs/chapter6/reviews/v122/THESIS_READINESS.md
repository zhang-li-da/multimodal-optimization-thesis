# 第六章能否成立：v1.2.2 独立评估

版本 review-v122.1，2026-09-25；代码依据 `44bafd2344d6a25e247c93c62280e6bf20e5e508`。

## 1. 直接判断

**可以进入第六章的正式研究与开题展示阶段；还不能把第六章作为已完成的方法贡献收口。** 当前障碍主要是证据，而不是缺少一个更大的 agent 框架。

| 用途或主张 | 当前判断 | 原因 |
|---|---|---|
| 开题中的研究基础、技术路线和原型演示 | 足够 | 已有真实历史搜索，且新运行器具备可追溯、恢复和独立测试链路 |
| 第六章的问题定义、算法描述、实现与前期研究 | 可开始写 | A/B/M 的职责、质量保护和有限分支开发可以具体定义 |
| 有限分支开发比不开发更有效 | 证据不足 | 新版本尚未真实比较；当前 16 次计划的两臂都有 B |
| 关系/族证据优于简单调度 | 证据不足 | 旧结果未支持优势；新 fixture 中没有族信息导致的选择差异 |
| 多个算法模式比单一算法更有用 | 尚未验证 | 当前输出主要是 validation 选出的单程序；独立部署选择器缺失 |
| 构成区别于近邻工作的博士方法贡献 | 尚未确立 | 需要明确机制差异、强基线、归因与独立验证；工程规范本身不等于创新 |

这里是研究证据成熟度判断，不以任意“完成百分比”代替学校或导师的具体章节要求。开题允许提出待验证假设；结题章节必须给出完成后的结论与边界。

## 3. 新结果回答了什么，没有回答什么

本轮 `readiness-20260925`：**真实模型调用 0、新在线搜索 0**。两个 fixture 各 8 个提案、16 次假 planner/coder 请求，实际执行受限评价；使用旧 r2 block 0，不使用新块 3–6。

| 指标 | FIFO fixture | 完整排序 fixture | 正确解释 |
|---|---:|---:|---|
| 有效生成候选 | 7/8 | 7/8 | 失败处理和候选评价能走通 |
| B 准入 / 后续尝试 | 2 / 4 | 2 / 4 | 额度与后续开发实际发生 |
| 成功扩展 / 最大成功深度 | 1 / 2 | 1 / 2 | 成功与尝试深度已分开 |
| 最佳 validation loss | 0.0582290764 | 0.0582290764 | 固定夹具输出，不能用于性能对照 |
| 有族分数差异的 B 时隙 | 0 | 0 | 此夹具没有提供族信息区分机会 |
| 完整排序与 gain-only 选择分歧 | 0 | 0 | 此夹具不能展示族证据的额外选择价值 |

**“没有暴露”不等于“机制无效”；“测试通过”也不等于“机制有效”。** 在构造的同历史机制用例 `two_branches` 中，FIFO 选父代 2，完整排序选父代 3；交换负面族证据后，完整排序改选 2。它证明代码会使用该信号，不证明在真实模型输出下该信号有预测价值。

真正的旧 r2 有 18 次搜索、144 个候选、141 个有效候选、288 次模型调用和 392,242 tokens。由原始运行表重新汇总：niche 平均 test gap 约 5.759%，旧固定开发约 5.569%，旧关系分支约 6.379%；旧关系减旧固定约 **+0.811 个百分点**，1/6 个模型×区块配对更好。

旧两臂的普通调度、W 引用和固定开发次序并未充分对齐，因此这个负结果不能单独归因于 B 内排序。新版已修正这些设计混杂，但没有新真实结果，故也不能把“设计修正”表述为“性能已经改善”。旧表的种子 test 最小值和 test oracle 是事后上界，不应作为可部署选择器成绩。

## 4. 与前三个研究章节如何形成主线

建议把本章暂定为：**面向自动算法发现的质量保护多模态搜索与有限分支开发方法**。关系引导是否进入最终标题，由独立归因结果决定。

| 前面章节的原则 | 第六章的自然延伸 | 必须补上的论证 |
|---|---|---|
| 第三章：质量与分布共同评价 | 分开报告程序质量、执行行为差异与集合用途 | 程序空间没有已知真实模式参考集，不能直接声称 DWD/峰召回率 |
| 第四章：离散结构、局部开发、关系记忆 | 搜索对象由单个解提升为能处理新实例的程序；保留竞争分支继续开发 | 解空间中的路线模式不能直接等同于跨实例程序模式 |
| 第五章：决策空间与目标空间兼顾 | 对程序质量和执行行为分别建模 | 当前未实现 HDADE 投影或完整多目标优化，不能写成它们已被严格迁移 |

本章最有研究价值的问题可以收敛为：**在有限 probe 和有限模型预算下，如何避免把有后续改进潜力的程序误判为无效重复，并把开发机会分配给更有价值的分支？**

定义程序 $p$、实例分布 $D$、损失 $L(p,x)$、固定 probe 上的行为描述 $b_P(p)$、开发算子及预算。有限样本上的行为接近只是操作性相似，不是语义等价或真实局部盆地证明。特别是距离阈值关系未必传递，代表档案不应被称为严格等价类划分。

建议在正文中明确：A 是质量约束的输出代表集；B 是有上限的后续开发机会；M 是实际观察到的反馈；W 当前不参与选择。`q(tag)` 是带平滑和回退的族级经验频率，不是校准成功概率，也不是父代×操作×终端的条件转移图。

## 5. 架构改善应按证据推进

### 现在必须做：收敛研究接口与对照

1. 继续使用当前可恢复运行器。完成最终协议，运行已准备的 16 次真实 F/R 筛查，不再为这个批次重构架构。
2. 后续版本统一一个分支排序接口，显式支持 N（无 B）、F（FIFO）、G（gain-only）、R（完整排序）。控制器内部已可表达 `niche`，但 **v1.2.2 runner 当前只接受 F/R**，不能只改 manifest 就声称四臂可执行。
3. 对族统计增加报告而非立刻改变算法：样本数、回退比例、可选 tag 数、评分差异、选择分歧，以及 `q` 项与 `0.25×gain/(1+attempts)` 项的尺度。若一个量级长期压倒另一个，先报告，再在新协议中检验归一化。
4. 保留每个完整候选的父代、修改族、实际行为、损失和成本，使 B 收益、族排序收益与总质量之间的链条可审计。单个节点成功不能替代总体对照。

### 条件满足后再做：解决一个具体失效机制

| 真实实验观察 | 合理改进 | 所需额外证据 |
|---|---|---|
| B 或多分支选择几乎不出现 | 先分析 8 步窗口是否过短；在新版本比较 8/16/32 步 | 共同预算下的暴露曲线与质量曲线；不能只给 R 加预算 |
| 族信息常回退，没有可辨识差异 | 收缩为共享先验，或研究带探索保底的不确定性分配 | 相同信息、相同额度的简单探索/UCB 对照；不能靠更复杂命名补证据 |
| R 与 G 有稳定差异且 R 更好 | 验证正确族对应是否必要，再考虑条件关系模型 | 打乱证据 P、模型外/新区块重复；避免稀疏图过拟合 |
| probe 合并了新实例上明显不同的程序 | 引入独立 witness 或描述符改进 | 冻结程序对的跨样本辨识率、新增评价成本与搜索增量 |
| 档案中有互补程序但单程序质量不升 | 研究部署选择器 | 新训练/开发/部署测试划分、同容量质量集合与种子集合对照 |
| W 被认为有价值 | 单独恢复 W 作为研究因素 | 条件于已有终端/父代/质量信息后仍有增量；不要用任意前缀代替优化轨迹 |

单个筛查不成功时，不必推倒运行器；保留基础设施，改变研究假设或缩小主张。若 F 有用而 R 无增量，论文可以转向有限质量保护开发，但仍需解释其区别于已有方法的具体贡献。

## 6. 创新性仍需近邻对照

本次重新读取作者原文摘要：[MLEvolve](https://arxiv.org/abs/2606.06473v1) 已包含跨分支引用、回顾记忆和规划编码分离；[SeaEvo](https://arxiv.org/abs/2604.24372v2) 描述策略语义簇、行为互补检索和饱和导航；[AdaEvolve](https://arxiv.org/abs/2602.20133v1) 描述基于改进信号的多层适应和预算调度。这些是限定创新主张的近邻，不是本仓库已经跑过的完整基线。

因此，“做了一个 agent”“用了多个候选”“加入记忆/重启”不宜单独作为新贡献。需要建立 **已知失效 → 明确定义 → 针对性机制 → 公平对照 → 可重复效果/边界** 的证据链。更详细的既有审计见 [NOVELTY_AUDIT.md](../../NOVELTY_AUDIT.md)；其中完整代码机制的历史判断不等于本次重新审计了所有外部代码。

最终实验至少加入一个机制最接近、可公平适配的外部方法；如果只能实现简化版本，必须称“某方法风格的适配基线”，说明保留/删除项，不冒称作者原版。不同任务、不同语言空间或预算下的论文成绩不能直接拿来比较。

## 7. 可以开始写的第六章结构

| 节 | 现在可写 | 最终需补 |
|---|---|---|
| 6.1 问题与章节联系 | 程序空间、多模态思想迁移、有限预算动机 | 用实验支持的失效案例 |
| 6.2 定义与评价 | 程序/行为/质量/B 额度/独立测试 | 模式辨识的操作性边界及指标 |
| 6.3 方法 | A/B/M、质量保护、分支开发及排序伪代码 | 消融后保留的最终机制，而非把所有历史版本拼成一个方法 |
| 6.4 可复现实验系统 | 当前 v1.2.2 链路 | 最终协议、真实服务信息、冻结结果 |
| 6.5 有效性与归因 | 旧 r2 作为探索性与失败诊断 | 新真实对照、外部强基线、成本与模型交互 |
| 6.6 多模态价值与边界 | 集合用途和辨识假设 | 独立集合/辨识实验、规模或第二任务验证 |
| 6.7 小结 | 研究范围 | 已证实、未支持与失效条件的明确区分 |

最小可辩护的完成状态不是“每项实验必须赢”，而是：一个清楚且有近邻差异的方法问题；可信独立结果；与简单/强基线相比的机制解释；多模态表征或多候选用途的直接证据；成本和失效范围。只有负结果而没有新的可解释贡献时，应继续研究，不能仅凭完整日志宣布章节创新完成。
