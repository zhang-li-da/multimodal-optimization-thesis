# 设计版本记录

## design-v2.0 — 2026-09-26

- 根据用户明确定位，将核心研究对象更新为智能体外层决策空间中的探索—开发协同。
- 修正此前把多程序集合部署收益作为章节必要证据的建议；单一最佳方案的发现质量、概率和效率可承担主要效果证据。
- 新增方向/谱系/行为三个 ID 的操作性区分和盲化核验；现有 A/B/M 不冒称已实现区域维护。
- 增加 SP/WR/FB/TS/AD 五策略比较及保护×反馈消融；N/F/G/R 保留为局部开发/排序专项。
- 区分扩大 TSP 城市规模与扩大外层模块空间；补充 Held–Karp 规模限制、参考值和负 gap 处理。
- 按输出校准、机制机会、策略筛查、消融、MLE、数学、独立确认建立阶段、预算与负结果决策。
- 固定并核查 MLEvolve 和 MLE-Bench 来源，说明模型默认值、限时后集成、私有评分、数学套件和数据问题的对齐边界。
- 新增当前研究定位的开题稿与根目录导航；v1.2.3 原型、结果、协议、旧开题稿及 demo 保留。
