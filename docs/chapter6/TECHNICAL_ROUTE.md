## 1. 研究目标与章节定位

输入为任务分布、程序接口、生成模型和总资源预算；输出为一组在新实例上质量合格、行为有所区别且具有用途的程序。任务用途应体现互补错误、鲁棒性、约束适配或可替代性；仅多输出几个代码文件不构成效用。

当前建议标题：**有限执行证据下自动算法发现的质量保护与分支开发机制**。关系排序是待验证模块。原始宽泛主张收敛成两个相连问题：

1. 有限执行证据怎样区分程序的表面差异、质量上有效的模式内改进，以及无收益的重复？
2. 在识别仍有不确定性时，如何安排开发、跨模式引用、重启与补充测试，使质量和有用替代方案在固定成本下改善？

第三章提供指标与可控基准；第四章提供离散解结构和起点—终端不一致的动机；第五章提供质量与行为两空间的分析原则。本章检验这些原则在昂贵、离散且受 LLM 分布影响的程序搜索中的成立条件。无需把前面每个算法模块都强行加入。

## 2. 两个层次的空间与模式定义

设程序空间为 $\mathcal P$，由合法语言、特征权限、运行限制和输入输出契约明确限定。对于实例 $x\sim D$，程序 $p$ 的任务损失为 $\ell(p,x)$，执行行为为 $b(p,x)$。目标质量是 $L_D(p)=\mathbb E_D[\ell(p,x)]$。

内层解空间中的路线或预测，不能直接当作外层算法模式。外层行为距离定义为

$$d_D(p,q)=\mathbb E_{x\sim D}[\delta(b(p,x),b(q,x))],\qquad 0\leq\delta\leq1.$$

TSP 可用路线边集 Jaccard 距离，装箱可用共箱关系，分类可用逐样本预测差异；还应按任务补充资源与鲁棒性行为，防止把输出相同但重要成本不同的程序错误合并。

严格的分布行为等价可定义为 $d_D(p,q)=0$；实际阈值 $d_D(p,q)\leq\rho$ 一般不具传递性。本方法应保留带区间的相似关系图，输出为质量合格的 $\rho$-分离代表集，避免把阈值图直接叫作真实吸引域。若要声称“局部最优模式”，必须进一步指定程序邻域/变异核与局部改进算子，并在受控环境证明或验证对应关系。

质量合格集合使用预先固定的参考与容差，例如 $L_D(p)\leq L_D(p_0)+\varepsilon$。工程搜索内部可使用当前最好质量，但外部比较需有跨方法共同门槛，避免各方法门槛宽度随自身表现变化。

## 3. 已实现的基础原型 v1 与修订动机

现有闭环为 planner → coder → AST 执行器 → A/W/M → 后续操作。A 保存质量门槛内的 probe 行为代表；W 保存部分执行轨迹或前缀；M 保存策略族、终端行为、碰撞、增益与费用。原版以 8 个给定策略标签统计生产率，并按改进、探索项和 collision 惩罚分配机会。

v1 的限制已由日志证实：有质量改进的程序也会碰撞；全局停滞与标签饱和容易触发大量重启；W 的跨任务意义不一致；成本被记录但未进入收益率；固定 probe 有误并/误拆风险。这些不是已经解决的问题。

v1.1 把质量保护与重启修正分开做了筛查，但完整修订版没有建立稳定质量优势；重放决策日志还显示信用记账未必改变后续父代选择。v1.2 因而把研究范围收窄到可直接观察的执行链：质量合格的父代相对改进是否被保留，并实际得到受预算限制的后续开发机会。完整方法的细节、r1 作废原因和 r2 结果见 V12_ARCHITECTURE.md 及 v1.2 技术报告。

## 3.1 v1.2：有限分支开发的实装边界

v1.2 将输出档案 A 与开发池 B 分开：A 负责质量/行为代表，B 最多保留三个有竞争力且有父代改进的规则，每个分支最多获得两个后续 proposal slots；已知规则重现不刷新额度。M 由可回放事件日志和有限标签统计实现。比较 `niche`、`niche + fixed development` 与 `relational branch`，采用相同准入及开发时隙规则；实际入池和续开发次数不同，普通调度也不同。

r2 达到预注册机制触发门槛，但关系分支的平均测试 gap 高于 fixed-development 对照。r2未实现独立witness、完整关系图和独立训练/部署selector，但继承的W实际参与关系路径参考选择；v1.2.1才显式关闭W。阶段结果说明分支执行机制可运行，未证明关系调度有质量增量；细节见 [v1.2 架构记录](V12_ARCHITECTURE.md)。

## 4. 拟议 v2：把“相似”与“无收益重复”分开

### 4.1 三种执行判断

对新程序 $p'$ 与参考 $p$，先分别评估：

- **质量增益：** 相对当前质量参照，是否取得超过噪声和实际意义门槛的改进。
- **行为关系：** 在独立执行证据下，是否已确认接近、已确认分离，或仍不确定。
- **互补用途：** 是否覆盖先前错误/约束失败、提高预定选择器或组合器的独立验证表现。

据此分类为：有用的模式内开发、有用的新模式、尚不确定的候选、以及无质量与互补收益的重复。只有最后一类可以计为“可避免的重复成本”。优质开发不得因行为相似而被直接惩罚。

### 4.2 独立 witness 与置信关系

固定 search-probe 可用于快速检索，但不能无限自适应查询后仍当成独立统计证据。对接近阈值、会影响重启或档案替换的关系，按预先规定的规则抽取新的 witness 实例；用于最终检验的 audit/test 始终不反馈。

对当次已确定的两程序，在独立 witness 集 $W_t$ 上计算 $\hat d_t$。允许三态判断：

$$\hat d_t+e_t<\rho:\text{确认接近};\qquad \hat d_t-e_t>\rho:\text{确认分离};$$

其余为不确定，可补充 witness 或延后决策。近似相似不强制聚成传递等价类；图的边保存区间、样本量、适用分布和版本。若新增 witness 改变关系，保留变更记录并重新检验依赖该关系的决策。

这里的“独立”指 witness 在程序确定后独立于此前搜索历史抽取。已被多次反馈的固定验证集不能满足这一条件。分类如果只能反复利用固定数据，需要独立储备样本或改用限定于有限池的随机化分析，不能套用无限总体采样定理。

### 4.3 意图—操作—终端转移图

保存关系记录

$$e_t=(a_t,o_t,z_t,\Delta L_t,\Delta U_t,c_t,h_t),$$

其中 $a_t$ 为父代或起始模式，$o_t$ 为修改/引用/重启动作，$z_t$ 为执行辨识后的终端代表或未决关系，$\Delta L_t$ 为质量进展，$\Delta U_t$ 为有用覆盖进展，$c_t$ 为实际成本，$h_t$ 为证据置信状态。规划标签是可用的解释特征，不能替代执行归类。

与仅记录代码—分数或标签频次相比，拟检验的增量是：相同起始模式和操作是否存在稳定的终端汇聚/转移规律，且这些条件关系能否预测下一次收益。如果打乱图边、只保留每个标签的均值后表现相同，就不能把图关系主张为贡献。

### 4.4 A/W/M 的严格分工

| 状态 | 保存内容 | 决策作用 | 不应承担的角色 |
|---|---|---|---|
| A | 质量合格且经辨识分离的程序代表、性能向量 | 输出、父代选择、互补检索 | 不用 A 数量直接充当真实模式召回 |
| W | 真正按时间或改进步骤形成的中间状态与增量 | 预测终端、寻找有效改动和互补路径 | 任意样本重排后的前缀不自动有轨迹意义 |
| M | 已消耗预算的转移、失败、无收益重复、关系区间 | 调度、重启、重新激活、补充测试 | 不把所有低分或相似候选永久判死 |

W 只有在条件于 A、终端、质量和成本之后仍有预测/决策增量才保留。否则使用简化 A/M 方法，并报告原因。HDADE 式投影也只在描述符维数带来可测量困难时进入独立消融。

### 4.5 成本感知且保护质量的资源分配

将动作收益拆为质量进展和经验证的用途增量：

$$r_t=\Delta Q_t+\lambda\Delta U_t.$$

二者尺度、实际意义门槛及 $\lambda$ 在开发任务上固定。成本包含 planner、coder、反思、embedding、补充 witness、执行、修复和失败调用；新颖性或省费声明不能遗漏辅助调用。

对候选操作族 $o$，使用收益与成本的条件估计，例如

$$S_t(o)=\frac{\widehat\mu_r(o)+\beta_t\,u_r(o)}{\max(c_{\min},\widehat\mu_c(o))},$$

并保留预定比例的探索机会。这个表达式是待实现的决策方案，不是已有后悔界保证。更稳妥的第一版可先采用质量优先的词典序约束：在质量非劣的操作中比较有用覆盖收益率，避免用未经校准的权重兑换质量。

重启必须依据“该关系下低收益且证据足够”而触发；不确定时留有继续或补测机会。有质量进展的同模式路径保留父代。重新激活按固定最低探索规则或分布漂移触发，避免短暂坏样本导致永久丢弃。

## 5. 可以证明的性质及其限制

### 5.1 独立 witness 的有限辨识界

假定一次决策前程序均已固定，在其后独立抽取 $m_t$ 个实例，单实例距离属于 [0,1]。当次比较数至多 $J_t$，按 Hoeffding 和并集界，可取

$$e_t=\sqrt{\frac{\log(2J_t/\alpha_t)}{2m_t}}.$$

若 $\sum_t\alpha_t\leq\alpha$，则所有登记比较同时满足区间覆盖的概率至少为 $1-\alpha$。例如取 $\alpha_t=6\alpha/[\pi^2(t+1)^2]$。证明仅用每次条件于历史的独立性、单次浓缩及可数并集界。

其中 $m_t$ 必须在该次新样本结果可见前确定。若按结果反复追加样本并随时停止，应把每次查看都登记为新的置信检查并分配误差额度，或使用有效的置信序列；不能对任选停止直接沿用单次固定样本区间。results/witness_mechanism.md 中的示例采用预先固定的七个查看时点，并对它们作 Bonferroni 分配。

它保证的是已比较程序在给定分布上的距离区间，不保证找到全部程序模式、不保证关系传递、不保证生成模型能到达未发现区域。固定 probe 被搜索反复访问时，不能直接用该式。该界可能很保守，实验必须记录达成目标精度需要多少额外执行。

### 5.2 档案有效性

如果每个入档候选均通过共同质量门槛，且与已有代表的距离下界超过 $\rho$，则在上述置信事件上，输出代表集满足相应质量与两两分离条件。质量若有随机性，也需独立质量区间控制；不能把单次训练分数当成确定真值。

这是一条条件有效性性质，不是模式覆盖最优性。贪心档案不保证最大基数，LLM 生成也没有自动的完备性。

### 5.3 预算与开销

有界解释器保证一次规则执行的操作数有限；准入器只在保守调用上界可支付时发起请求，并核查实际 usage。因此在提供方遵守已核查的使用量契约时，总调用 token 不超过预定上限。若输入 token 规则不透明或错误请求无 usage，必须记录契约失效或改用提供方原生计数，而不是宣称无条件预算保证。

若最多保留 $a$ 个 A、$w$ 个 W、$m$ 条 M，每个描述符维数 $d$，朴素候选更新为 $O((a+w+m)d)$ 的比较开销，另加图统计和真实求值。实际代码还需区分原始日志存储量与在线内存上限。复杂度不是经验效率的替代，必须报告端到端费用。

不建议为这一版本承诺程序搜索全局收敛或一般 bandit 次线性后悔界：自适应候选空间、非平稳模型抽样、动态档案和相关评估不满足标准结论的直接条件。

## 6. 技术流程与版本验收

当前已实现流程：任务契约与预算 → 初始规则 → 规划/编码 → 受限执行 → 质量、逐实例损失与行为记录 → 有限证据分类 → A 输出档案与 B 开发池分流 → 固定或关系引导的续开发 → 冻结 validation 选优 → 独立 test。

未来扩展流程（尚未实现）：按需抽取独立 witness → 三态关系置信更新 → 经消融证明有用后再加入关系图或 W → 在独立确认任务上评价成本与多算法用途。不能把未来流程画成当前成果。

版本推进按以下门槛执行，任何一步失败都需回到该步修正：

1. **v1/v1.1 失效复核（已完成）：** 结果解释简单小生境未被完整修订版稳定超过，且 credit/restart 的部分修改缺少足够的决策触发。
2. **v1.2 执行链筛查（已完成）：** 真实模型搜索触发有限分支开发；关系控制器整体未超过固定开发基线，排序独立效果未隔离。
3. **机制诊断与新协议（下一步）：** 先定位关系评分、标签稀疏、分支淘汰与提示预算的影响；决定保留或删除复杂调度，再冻结足够多的独立区块和第二任务。
4. **独立确认与章节验收（未完成）：** 验证算法集合的可部署用途和跨任务效果，加入来源明确的强基线，按相同预算报告质量、用途和成本。witness、W、关系图只在核心机制显示增量后再投入。

完整实验数量、预算、统计、强基线和停止条件见 EXPERIMENT_DESIGN.md。若 v1 未通过，不把 v2 路线写成“已有效的最终技术路线”，而是待验证的替代研究方案。

## v1.2 r2 复核与当前范围锁定

r2 的执行链已经被真实模型触发，但复核显示普通调度、W 引用和深度统计仍
混入了开发策略比较。当前只做不调用模型的机制修正：

1. 在两个开发臂之间共享普通 `niche` 调度，只保留 B 内选择作为处理因素；
2. 将 W 明确设为审计字段，禁止它改变父代和参考对象；
3. 将固定臂的规则写成“按创建顺序耗尽最老分支”，不再把轮转实现称为 FIFO；
4. 同时报告分支尝试深度和连续成功改进深度；
5. 用两个同时可选分支的确定性夹具检验关系评分是否真的改变选择，并检验
   非开发步骤的决策一致性。

这些检查位于 `experiments/chapter6/v12_1/`，没有追加任何模型搜索。未来的
16 次搜索只是未来独立协议草案，不能与 r2 合并，也不能把机制门槛结果写成
性能确认。
