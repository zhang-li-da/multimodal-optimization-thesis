# v1.2.3 离线演示与开题讲解

双击 [离线回放页面](../../experiments/chapter6/v12_3/results/minimax-20260926-r1/demo/index.html) 即可使用，无需 Python、OpenCode 或 API 凭据；在 GitHub 网页上请先下载文件或拉取仓库。数据、CSS 和脚本都包含在 HTML 内，无外部字体、CDN、fetch 或模型请求。

备用交付包括 [4 分 20 秒字幕演示](../../experiments/chapter6/v12_3/results/minimax-20260926-r1/demo-evidence/video/chapter6_demo_4m20s.mp4)、同名 SRT 字幕、[分镜数据](../../experiments/chapter6/v12_3/results/minimax-20260926-r1/demo-evidence/video/storyboard.json) 以及 [浏览器截图与验证记录](../../experiments/chapter6/v12_3/results/minimax-20260926-r1/demo-evidence/)。视频由真实浏览器画面按脚本定时导出，**不是现场 API 调用录屏，没有配音，也不模拟模型正在生成**。

## 演示 A：历史真实回放

左侧选择“真实搜索回放”。默认运行是原 r2 manifest 顺序中首个“候选入池后被实际继续开发”的 minimax-niche_fixed_dev-b0。所有 18 次运行可在下拉框选择，整批结果一直可查看；默认案例只说明执行链，不估计平均效果。

| 时间 | 操作与讲述 |
|---|---|
| 0:00–0:30 | 展示共同初始规则、A/B/M 和 8 时隙预算。外层搜索对象是跨实例程序，路线由内层执行得到。 |
| 0:30–1:00 | 前进到提案 1、2。p3 入池并被继续开发，p4 获得新进步。点击节点查看意图、源码和父代差异。 |
| 1:00–1:30 | 前进到提案 3、4。成功改进深度达到 3；下一次失败开发正常扣除机会，不增加成功深度。 |
| 1:30–2:00 | 展示质量不足的新行为、后续失败与额度消耗。A 中代表、B 中可开发节点和全部已执行节点不完全相同。 |
| 2:00–2:15 | 切到最后一步和整批结果。历史均值 niche 5.759%、固定开发 5.569%、关系开发 6.379%。明确旧轮转调度与 W 混杂。 |

历史画面使用旧版真实控制器重放，不把旧固定开发说成严格 FIFO。界面成功深度按成功准入链重新计算，保留原始历史日志不改写。展示的源码不会在网页中执行。

## 演示 B：合成控制用例

| 时间 | 操作与讲述 |
|---|---|
| 2:15–2:45 | 选择“机制控制用例”。p2、p3 的局部收益和使用次数相同；local_distance 有两次额外失败。真实 V121 控制器输出 F 选 p2、R 选 p3。 |
| 2:45–3:00 | 点击“失败记在 return_aware”，R 改选 p2。说明选择随证据归属而变。 |
| 3:00–3:15 | 点击“均退回共享统计”，两分支 q 相同；当前同收益历史下选择一致。 |
| 3:15–3:45 | 展示一次预先规定的无效反馈：选中分支机会减少 1，成功深度不增长。不要虚构这个选择会带来更好子代。 |

该用例的数值与父代选择来自既有 two_branches 合成历史和真实控制器。它证明规则可以响应证据，不能证明真实模型搜索收益。

## 演示 C：本轮筛查与待验证主张

3:45–4:20 选择“本轮筛查”。这里呈现新版真实 MiniMax M3 记录，按独立批次列 16 次搜索结果、全部失败提案和最终 test。与旧 r2 不合并统计。

结尾可用：“当前原型能把质量合格的局部改进转化为可执行且有上限的分支开发。要建立方法贡献，还需要证明分支间存在实际选择机会、选择能带来增量，并且保留多个程序能在新实例上创造用途。本次实验与失败记录为这些问题提供可复核依据。”

## 复核与再生成

1. 查看 demo/provenance.json，核对默认案例、历史运行数、合成选择和页面哈希。
2. 浏览器验收脚本遍历全部历史和当前画面、测试按钮与滑块、切换三种合成证据、检查小屏幕溢出和网页网络请求。
3. 需要再生成时，先按 v12_3/README.md 解包原始研究目录；输出到新目录，不覆盖首次交付文件。
4. 生成和回放均不使用模型。视频导出额外需要 websocket-client、Pillow、numpy 及本地 ffmpeg；观看 HTML 和 MP4 无需这些依赖。

本轮对视频工具的安装只写入未跟踪的本地工具目录，没有修改冻结搜索环境的依赖版本。浏览器使用独立临时配置并在检查结束后关闭。
